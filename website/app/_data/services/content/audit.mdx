## Аудит (RU)

Мы проводим детальный анализ вашего проекта: от инфраструктуры и кода до пользовательского опыта. Находим узкие места, оцениваем риски и предоставляем пошаговый план исправлений.

### Что входит:
- Аудит архитектуры и безопасности
- Проверка производительности (Core Web Vitals)
- Юзабилити-тестирование
- Отчёт с приоритетами и оценкой сроков

## Audit (EN)

We conduct a detailed analysis of your project: from infrastructure and code to user experience. We find bottlenecks, assess risks, and provide a step-by-step remediation plan.

### What's included:
- Architecture and security audit
- Performance check (Core Web Vitals)
- Usability testing
- Report with priorities and time estimates
