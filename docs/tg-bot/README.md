# tg-bot

Aiogram 3 bot for Rovno.dev. Handles admin notifications and deep-link account binding.

## Run

```bash
docker compose -f docker-compose.dev.yml up -d tg-bot
```

Logs:

```bash
docker compose -f docker-compose.dev.yml logs -f tg-bot
```
