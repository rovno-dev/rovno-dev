## Веб-разработка как инженерная дисциплина

Сайт — это не картинка, которую кто-то оживил. Это система, у которой есть владелец, команда поддержки, отдел маркетинга и аналитики. Хорошая разработка — та, где все эти стороны не мешают друг другу.

Мы делаем сайты и веб-приложения на современном стеке с фокусом на три вещи: скорость, поддерживаемость и измеримость. Не «красиво на демо», а «работает через три года».

## Что входит в работу

### Проектирование

Начинаем с модели данных и сценариев использования. Не рисуем макет, пока не понимаем, как устроена предметная область. Для сложных продуктов проектируем API-контракты и схему БД до того, как пишем первую строчку фронтенда.

### Разработка

Стек, на котором мы работаем: Next.js (App Router) для фронтенда, FastAPI для бэкенда, PostgreSQL для данных, Redis для кеша. Docker Compose или Kubernetes для инфраструктуры. Мы не привязаны к стеку — если у вас есть своя команда с другим стеком, подстроимся.

### Инфраструктура

CI/CD, мониторинг, логирование, бэкапы, безопасность. Разворачиваем в вашем облаке или у нас. Настраиваем так, чтобы деплой одной командой был нормой, а не событием.

## Как проходит работа

### Discovery — 1–2 недели

Разбираем задачу, рисуем схему, оцениваем объём. На выходе — техническое задание с оценкой по этапам.

### Разработка — спринты по 2 недели

Демо в конце каждого спринта. Никаких «покажем через три месяца». Вы всегда видите прогресс и можете скорректировать направление.

### Релиз и сопровождение

Первые две недели после релиза — сопровождение включено. Затем — поддержка по SLA или передача вашей команде с документацией.

## Что получаете на выходе

- Работающий продукт в продакшене
- Исходный код в вашем Git-репозитории
- Документация по архитектуре и API
- Настроенная инфраструктура (CI/CD, мониторинг, бэкапы)
- План дальнейшего развития и оценки по следующим фичам

## Технологии

Мы не привязываем вас к конкретному стеку, но чаще всего работаем с:

- **Frontend:** Next.js 16+, React 19+, Tailwind CSS v4
- **Backend:** Python 3.12+, FastAPI, SQLAlchemy 2.0
- **Database:** PostgreSQL 15+
- **Cache/Queue:** Redis, Valkey
- **Infrastructure:** Docker, Traefik, GitHub Actions
- **Monitoring:** Sentry, Grafana, Loki

## Кому это подходит

Стартапам, которым нужен MVP за разумные деньги и сроки. Продуктовым командам, которым нужна помощь с архитектурой или реализацией. Компаниям, которые переросли свой сайт на конструкторе и хотят собственный продукт.
